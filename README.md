A one-line voicemail greeting recorded by a cat named Miso, napping in the box you threw away — written by a deterministic Python program for make.fun's "Funniest Cat Voicemail Greeting" bounty.

## Run it

```sh
python3 main.py
```

This writes the greeting (117 characters) to `/output/entry.txt`.
